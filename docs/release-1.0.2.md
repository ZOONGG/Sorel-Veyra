# Veyra 1.0.2

- Восстановлен современный ClickGUI: темы, Inter, уведомления, поиск, избранное и две колонки.
- Компактные бинды на уровне звезды и переключателя. Размер кнопки остаётся постоянным при назначении; крестик удаляет бинд, Escape отменяет, таймаут 3 секунды очищает его.
- Sprint использует ванильный ввод после обновления движения; Omni удалён.
- Исправлен Sneak key pressed в Bridge Assist, включая переназначенные клавиши и восстановление ввода. Удалены Sneak on jump и Avoid double-sneaking.
- AutoBlock сохранён с предупреждением HIGH RISK. AutoBlockIn удалён; старые конфигурации загружаются совместимо.
- Timer и Experimental Freeze сохранены из 1.0.1. Механизм раскрытия карточек сохранён.

Java 17. Сборка проверена автоматическими тестами и отдельным OpenGL/input smoke без запуска Minecraft. Финальный тестовый вариант с компактными биндами принят пользователем. Полная игровая проверка Sprint/Bridge Assist в рамках автоматических проверок не проводилась.
